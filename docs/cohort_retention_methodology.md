# Membership Cohort Retention Methodology

## Purpose

This document defines the cohort-retention methodology used by the Membership Data Operations layer of the Next Best Action Decisioning Lab.

All membership data is synthetic.

The cohort analysis complements the 30-day retention KPI by showing how membership survival changes as cohorts age over multiple calendar months.

---

## Reporting Reference Date

The initial fixed reporting date is:

`2026-09-21`

No cohort observation is allowed beyond this date.

---

## Cohort Definition

A membership cohort is defined by the calendar month in which a member joined.
